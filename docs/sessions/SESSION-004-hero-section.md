# Session 04 — Hero Section

## Goal

Start building the actual portfolio homepage.

## Completed

* Added semantic page structure:

  * `main`
  * `section`
  * `h1`
  * `p`
  * `a`
* Introduced the first Hero section.
* Added placeholder Hero content.
* Introduced the first global stylesheet.
* Moved global styles from `Layout.astro` to `global.css`.
* Learned the difference between HTML structure and CSS presentation.
* Added the first CSS class (`hero`).
* Added the first CSS rules:

  * `padding`
  * `display: flex`
  * `gap`
* Grouped Hero actions into a dedicated container (`hero-actions`).
* Learned basic Astro routing using the `pages` directory.

## Key concepts learned

* Semantic HTML
* Layout vs Page responsibilities
* Global CSS
* CSS selectors
* CSS classes
* Flexbox (introduction)
* Separation of structure and presentation

## Notes

The Hero section intentionally remains visually simple.

The next session will focus on visual styling, including typography, spacing, buttons, colors, CSS variables and the first responsive layout.

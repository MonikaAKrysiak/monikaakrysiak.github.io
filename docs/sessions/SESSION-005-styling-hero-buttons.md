# Session 05 — Styling the Hero

## Goal

Introduce the project's visual identity by building the first reusable UI component and establishing the foundations of the design system.

## Completed

- Introduced CSS custom properties (design tokens) using `:root`.
- Defined the initial project color palette.
- Applied the first global theme colors.
- Learned how CSS variables work with `var()`.
- Replaced hardcoded values with reusable design tokens.
- Created the first reusable Button component.
- Split button styles into:
  - `.button`
  - `.button-primary`
  - `.button-secondary`
- Styled primary and secondary call-to-action buttons.
- Added button hover states.
- Introduced smooth CSS transitions.
- Applied subtle border radius for a consistent visual style.
- Learned the purpose of reusable utility classes instead of page-specific styling.

## Key concepts learned

- CSS Custom Properties
- Design Tokens
- CSS Variables
- `:root`
- Component-based styling
- Reusable CSS classes
- Descendant selectors
- CSS inheritance
- Browser default styles (User Agent Stylesheet)
- Pseudo-classes (`:hover`)
- CSS transitions
- Shorthand properties (`padding`, `border`)

## Notes

The project now has its first reusable UI component and the foundations of a scalable design system.

Future sessions will focus on typography, spacing, layout and responsive design.

# ADR-001 – Project Principles

## Status

Accepted

---

## Context

Before choosing technologies, the overall development philosophy should be established.

The project is intended not only as a portfolio but also as a long-term learning project.

---

## Decision

The project will follow these principles:

- understand before using,
- security by default,
- quality over speed,
- small iterative development,
- clean and maintainable code,
- minimal unnecessary dependencies.

Artificial Intelligence is treated as a mentor and pair programmer, not as a replacement for understanding.

---

## Consequences

Advantages:

- better understanding of the technologies,
- easier maintenance,
- higher code quality,
- better engineering habits.

Trade-offs:

- slower progress,
- more documentation,
- more conscious decision making.
